Spreadsheet

Charts

This group adds and manages charts on a sheet. It can insert nine chart types — bar/column, line, pie, area, scatter (XY), bubble, doughnut, radar and a bar + line combo — and then edit an existing chart: change the data it points at, set the chart or axis titles, show or hide the legend, apply a built-in style, and move, resize, reposition or delete it.

Prerequisite: before using any of these instructions, the workflow must already have an XLSX spreadsheet created or opened (with Create spreadsheet). Every instruction works on a sheet (tab) inside that spreadsheet, identified by name (Sheet1 by default), which must already exist — and the data the chart shows should already be in its cells.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used. If the document doesn’t exist, the instruction simply does nothing.

  • The sheet must already exist: the Sheet name field chooses which tab the instruction works on, and defaults to Sheet1. If no sheet with that name is found, the instruction does nothing and the workflow continues with the next instruction.

  • Data ranges use spreadsheet notation: fields like Category range, Values range, X range, Y range and Size range point at the cells that hold the data, written the spreadsheet way — Sheet1!$A$1:$A$5. The chart stores these references; the bars, lines and slices are drawn when you open the file in a spreadsheet app.

  • Where the chart sits (anchoring): the Insert instructions place a chart by its top-left anchor cell — Anchor column and Anchor row, both counted from 1 (1 = column A / the first row) — and a size given in whole cells: Width in columns and Height in rows. A width or height of 0 (or a negative one) would make the chart invisible, so it is raised to one cell.

  • A chart needs data: if the Values range (the Y range on scatter and bubble charts) is left empty, the Insert instruction does nothing rather than adding an empty chart. Likewise, Change Chart Data Range with an empty range and Set Chart Title / Set Axis Title with empty text leave the chart as it is instead of blanking it.

  • Which chart (chart number): instructions that edit an existing chart identify it by its position on the sheet, Chart number, counted from 1 in the order the charts were added (the first chart is 1, the second 2, …). If there is no chart at that position, the instruction does nothing and the workflow continues with the next instruction.

  • Saving the new chart’s number: every Insert instruction offers a Save chart number field. Fill it in with a name and the position of the chart it just created is saved under that name — so you don’t have to count the charts already on the sheet. Feed it straight into the Chart number (from variable) field of any instruction that edits a chart.

  • Chart style: a built-in style number from 1 to 48. In the Insert instructions a Style index of 0 means “no explicit style”.

  • Dynamic values (@name): in any text field (sheet name, ranges, titles, series names, legend position, axis, …) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.

  • “From variable” fields: the @name trick only works in text fields. The number options (like Chart number, Style index, Anchor column, Width in columns, Hole size, …) each have a companion “from variable” field:

    • If you leave it empty, the value chosen in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and reads the number from that variable.

    This is mainly for chaining instructions. If you only work with fixed values, you can ignore these fields.

Apply Chart Style .xlsx

Applies one of the built-in visual styles to an existing chart.

When to use it: to restyle a chart you already inserted — changing its colors and overall look in one step.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab holding the chart. Supports @name Sheet1 No
Chart number Which chart on the sheet, counted from 1 1 No
Style index Built-in style number 1–48 2 No
Chart number (from variable) Reads the chart number from a saved value (empty) No
Style index (from variable) Reads the style number from a saved value (empty) No

Important behavior: the style number is clamped to the 1–48 range. If there is no chart at Chart number, the instruction does nothing.

Change Chart Data Range .xlsx

Repoints an existing chart at different data ranges, without recreating it.

When to use it: when the chart is fine but the cells it should read have changed (for example after adding more rows of data).

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab holding the chart. Supports @name Sheet1 No
Chart number Which chart on the sheet, counted from 1 1 No
Category range New range for the categories / X values. Supports @name Sheet1!$A$1:$A$5 No
Values range New range for the values / Y values. Supports @name Sheet1!$B$1:$B$5 No
Chart number (from variable) Reads the chart number from a saved value (empty) No

Important behavior: updates every series in the chart — the category (and scatter/bubble X) references are set to Category range, and the value (and Y) references to Values range. If there is no chart at Chart number, the instruction does nothing.
