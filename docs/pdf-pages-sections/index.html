PDF

Pages & sections

This group manages the structure of a PDF across pages and sections: adding new sections with their own page setup, page breaks, section headers and footers, automatic page numbers, and adding or duplicating whole pages. Use it to organize a longer document into parts and to number its pages.

Prerequisite: before using any of these instructions, the workflow must already have a PDF created (with Create PDF).

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used. If the document doesn’t exist (or is not a PDF), the instruction simply does nothing.

  • When instructions take effect: Add Section, Add Page Break, Add Section Header, Add Section Footer, Add Page Number, and Add Page Number Of Total change the document right away. Add Blank Page and Duplicate Page are recorded now and applied when the PDF is saved (when it is rendered to the final file) — their effect appears in the finished .pdf, not before.

  • Sections and page numbers start at 1. The Section number is 1 for the first section, 2 for the second, and so on; out-of-range numbers are adjusted to the nearest valid section. Likewise a Page number of 1 is the first page, adjusted to the nearest valid page if out of range.

  • Dynamic values (@name): in a text field (page format, header/footer text, alignment, prefix, separator) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.

  • Saving a result (Save page count): Add Blank Page and Duplicate Page can save the document’s total page count (after the page is added) into a named value, so a later instruction can reuse it. Leave it empty not to save anything.

  • Measurements are in centimetres. Section margins, page margins, custom page sizes, shapes, images, and clickable areas all use centimetres. Only typography keeps its own unit: font sizes, text spacing, and line/border thickness are in points. The unit is always written in the field’s name.

  • “From variable” fields: the @name trick only works in text fields. The numeric fields At position, Section, Page number, and the four margins of Add Section each have a companion “from variable” field:

    • If you leave it empty, the value typed in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and reads the value from that variable.

    This is mainly for chaining instructions. If you only work with fixed values, you can ignore these fields. (The yes/no fields Landscape and In header have no “from variable” companion.)

Add Blank Page .pdf

Adds an empty page to the document, either at the end or at a chosen position.

When to use it: to insert a deliberately blank page — for example a separator before a new part, or to make the following content start on a fresh page.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
At position Position (1 = before the first page) where the blank page is inserted. 0 = at the end 0 No
At position (from variable) Reads the position from a saved value (empty) No
Save page count Saves the document’s total page count after adding the page (empty) No

Important behavior: this instruction is applied when the PDF is saved. If At position is between 1 and the current number of pages, the blank page is inserted before that position; otherwise (including 0) it is appended at the end.

Add Page Break .pdf

Inserts a page break at the end of the last section, so the following content starts on a new page.

When to use it: to force the next content onto a fresh page without creating a whole new section.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No

Important behavior: the break is added to the last section. If the document has no section yet, nothing happens.

Add Page Number .pdf

Inserts an automatic page number into the header or footer of a chosen section.

When to use it: to number the pages of the document (for example “Page 1”, “Page 2”…).

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Section Which section to add the page number to (1 = first section) 1 No
In header Yes = put it in the header (top); No = in the footer (bottom) No No
Alignment Horizontal alignment: left, right, or center center No
Prefix Text shown before the number. Supports @name "Page " No
Section (from variable) Reads the section number from a saved value (empty) No
In header (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: the page number updates automatically per page. The prefix is added only if it is not empty. The section number is adjusted to the nearest valid section if out of range; if the document has no section, nothing happens. An unrecognized alignment falls back to center.

Add Page Number Of Total .pdf

Inserts an automatic “Page X of Y” field (current page and total pages) into the header or footer of a chosen section.

When to use it: to number pages while also showing how many there are in total (for example “Page 3 of 10”).

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Section Which section to add the field to (1 = first section) 1 No
In header Yes = put it in the header (top); No = in the footer (bottom) No No
Alignment Horizontal alignment: left, right, or center center No
Prefix Text shown before the current page number. Supports @name "Page " No
Separator Text shown between the current page and the total. Supports @name " of " No
Section (from variable) Reads the section number from a saved value (empty) No
In header (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: both numbers update automatically. The prefix is added only if it is not empty. The section number is adjusted to the nearest valid section if out of range; if the document has no section, nothing happens. An unrecognized alignment falls back to center.

Add Section .pdf

Adds a new section to the document with its own page setup (size, orientation, and margins). Content added afterwards goes into this new section.

When to use it: to start a new part of the document that needs a different page format or orientation — for example a landscape section for wide tables in an otherwise portrait document.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Page format Standard paper size for the new section, picked from a list: A3, A4, A5, Letter, or Legal A4 No
Landscape Yes = landscape; No = portrait No No
Top margin Top margin in centimetres 2.5 No
Bottom margin Bottom margin in centimetres 2.5 No
Left margin Left margin in centimetres 2.5 No
Right margin Right margin in centimetres 2.5 No
Landscape (from variable) Reads the yes/no value from a saved value (empty) No
Top margin (from variable) Reads the top margin from a saved value (empty) No
Bottom margin (from variable) Reads the bottom margin from a saved value (empty) No
Left margin (from variable) Reads the left margin from a saved value (empty) No
Right margin (from variable) Reads the right margin from a saved value (empty) No

Important behavior: the new section starts from the document’s default page setup and then applies the format, orientation, and margins you provide. An unrecognized page format falls back to A4.

Add Section Footer .pdf

Adds a line of text to the footer (bottom of every page) of a chosen section.

When to use it: to show a running note, confidentiality label, or similar text at the bottom of the pages of a section.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Section Which section’s footer to write to (1 = first section) 1 No
Text The footer text. Supports @name (empty) No
Alignment Horizontal alignment: left, right, or center center No
Section (from variable) Reads the section number from a saved value (empty) No

Important behavior: the section number is adjusted to the nearest valid section if it is out of range. If the document has no section, nothing happens. An unrecognized alignment falls back to center.

Add Section Header .pdf

Adds a line of text to the header (top of every page) of a chosen section.

When to use it: to show a running title, chapter name, or similar text at the top of the pages of a section.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Section Which section’s header to write to (1 = first section) 1 No
Text The header text. Supports @name (empty) No
Alignment Horizontal alignment: left, right, or center center No
Section (from variable) Reads the section number from a saved value (empty) No

Important behavior: the section number is adjusted to the nearest valid section if it is out of range. If the document has no section, nothing happens. An unrecognized alignment falls back to center.

Duplicate Page .pdf

Makes a copy of an existing page and appends it at the end of the document.

When to use it: to repeat a page — for example duplicating a template or cover page.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Page number The page to copy (1 = first page) 1 No
Page number (from variable) Reads the page number from a saved value (empty) No
Save page count Saves the document’s total page count after adding the copy (empty) No

Important behavior: this instruction is applied when the PDF is saved. The copy reflects the document’s content at the moment this instruction runs and is always added at the end. The page number is adjusted to the nearest valid page if it is out of range.
