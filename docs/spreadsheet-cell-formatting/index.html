Spreadsheet

Cell formatting

This group controls how cells look. It sets the font (family, size, bold, italic, underline, strikethrough, color), the cell background (a solid fill or a pattern), the alignment of the text (horizontal, vertical, wrap, rotation, indent), the cell borders, and the number format (plain number, currency, date, time, percentage or forced text). Two extra instructions work at a higher level: one applies a built-in named style in a single step, and another copies the formatting of one cell onto other cells (like a format painter).

Prerequisite: before using any of these instructions, the workflow must already have an XLSX spreadsheet created or opened (with Create spreadsheet). Every instruction works on a sheet (tab) inside that spreadsheet, identified by name (Sheet1 by default), which must already exist.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used.

  • The sheet must already exist: the Sheet name field chooses which tab the instruction works on, and defaults to Sheet1. If no sheet with that name is found, the instruction does nothing and the workflow continues with the next instruction.

  • Cells and ranges: each instruction works on a Cell range, which can be a single cell (A1) or a rectangular range written top-left:bottom-right (A1:C3). The formatting is applied to every cell in that range. Cells that don’t exist yet are created automatically.

  • Colors are given as hex: the color fields take a hex code, either 6 digits (RRGGBB — the usual red-green-blue code, e.g. FF0000 red, FFFF00 yellow) or 8 digits with opacity in front (AARRGGBB). A leading # is optional (#FF0000 works too). Each instruction lists its default color.

  • Dynamic values (@name): in any text field (sheet name, range, color, font name, style name, alignment, format code, …) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.

  • “From variable” fields: the @name trick only works in text fields. The number fields (Size in points, Degrees, Indent level, Decimal places) and the yes/no options (Enabled, Thousands separator, Percentage, Symbol before) each have a companion “from variable” field:

    • If you leave it empty, the value typed in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and reads the value from that variable.

    This is mainly for chaining instructions (one instruction saves a value, the next one reads it). If you only work with fixed values, you can ignore these fields.

Apply Predefined Style .xlsx

Applies a built-in named cell style (like Normal, Good, Bad, Heading 1) to a range in one step.

When to use it: to give cells a ready-made look — a “Good”/“Bad” traffic-light style or a heading style — instead of setting font, fill and border by hand.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to apply this to. Supports @name Sheet1 No
Cell range Cell or range to style (A1, A1:C3). Supports @name A1 No
Style name Name of the built-in style to apply. Supports @name Normal No

Important behavior: only styles already defined in the spreadsheet can be applied; the name is matched ignoring upper/lower case. Normal always exists; others (Good, Bad, Neutral, Heading 1, …) apply only if the spreadsheet already defines them. If the style isn’t found, nothing happens.

Copy Cell Format .xlsx

Copies all the formatting of one cell onto another cell or range (a format painter).

When to use it: when you’ve formatted one cell just right and want the same look on other cells, without redoing every setting.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to work on. Supports @name Sheet1 No
Source cell address The cell to copy the formatting from (A1). Supports @name A1 No
Target cell range The cell or range to paste the formatting onto (B1, B1:B10). Supports @name B1 No

Important behavior: only the formatting is copied, not the value. If the source cell doesn’t exist (or its address is invalid), nothing happens.

Set Bold .xlsx

Turns bold on or off for a range.

When to use it: to emphasize headers or totals.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to work on. Supports @name Sheet1 No
Cell range Cell or range to change (A1, A1:C3). Supports @name A1 No
Enabled On = make bold; Off = remove bold Yes No
Enabled (from variable) Reads the on/off value from a saved value (empty) No

Important behavior: with Enabled off, any existing bold is removed from the range.

Set Border .xlsx

Draws borders around the cells of a range.

When to use it: to outline a table, underline a total row, or box a group of cells.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to work on. Supports @name Sheet1 No
Cell range Cell or range to border (A1, A1:C3). Supports @name A1 No
Sides Which sides to draw (see below). Supports @name All No
Border style Line style, chosen from a list (see below) Thin No
Color Border color, hex (6 or 8 digits). Supports @name 000000 (black) No

Important behavior: Sides is a comma-separated list of left, right, top, bottom, or all/outer for every side (e.g. top,bottom). Only the chosen sides are (re)drawn; sides you don’t list keep whatever they already had. Border style is picked from a list (thin, medium, thick, hair, double, dashed, dotted, medium dashed, dash dot, medium dash dot, dash dot dot, slant dash dot), so it cannot be typed freely and does not accept @name. Color may be left empty: the style is still drawn on the chosen sides and the color is left to the spreadsheet default.

Set Currency Format .xlsx

Formats numbers as currency (money), with a symbol and decimals.

When to use it: to show amounts as $1,234.00, 1.234,00 €, etc.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to work on. Supports @name Sheet1 No
Cell range Cell or range to format (A1, A1:C3). Supports @name A1 No
Currency symbol The money symbol to show. Supports @name $ No
Decimal places How many digits after the decimal point 2 No
Symbol before On = symbol before the amount ($100); Off = after (100$) Yes No
Thousands separator On = groups the digits in threes (1,234.00); Off = 1234.00 Yes No
Negative style How a negative amount is shown, chosen from a list minus No
Decimal places (from variable) Reads the decimals from a saved value (empty) No
Symbol before (from variable) Reads the before/after value from a saved value (empty) No
Thousands separator (from variable) Reads the yes/no from a saved value (empty) No

Important behavior: Negative style is picked from a list — minus (-$1,234.00), red (the same in red), parentheses (($1,234.00)) or redParentheses (the same in red) — so it cannot be typed freely and does not accept @name. The plain minus is the default: a colour nobody asked for used to arrive with the format, and it clashed with whatever colour rule the sheet already had. Only the display changes; the stored number is untouched.

Set Fill Color .xlsx

Paints a solid background color behind the cells.

When to use it: to highlight a header row, a total, or a group of cells with a flat color.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to work on. Supports @name Sheet1 No
Cell range Cell or range to fill (A1, A1:C3). Supports @name A1 No
Color Background color, hex (6 or 8 digits). Supports @name FFFF00 (yellow) No

Important behavior: applies a solid fill of the chosen color to every cell in the range. If Color is left empty nothing is applied — the color is the whole point of this instruction; to clear a fill, paint it with the background color you want.

Set Fill Pattern .xlsx

Fills the cell background with a pattern (stripes, dots, grid, …) instead of a flat color.

When to use it: to mark cells with a textured look, e.g. a striped fill to flag “pending” cells.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to work on. Supports @name Sheet1 No
Cell range Cell or range to fill (A1, A1:C3). Supports @name A1 No
Pattern type Which pattern to use, chosen from a list (see below); stored as darkhorizontal, darkvertical, darkdown, darkup, darkgrid, darktrellis, lighthorizontal, lightvertical, lightdown, lightup, lightgrid, lighttrellis, gray125 or gray0625 darkhorizontal (Dark horizontal) No
Foreground color Color of the pattern lines/dots, hex. Supports @name 000000 (black) No
Background color Color behind the pattern, hex. Supports @name FFFFFF (white) No

Important behavior: Pattern type is picked from a list of 14 patterns (dark and light versions of horizontal, vertical, down, up, grid and trellis, plus 12.5 % and 6.25 % gray), so it cannot be typed freely and does not accept @name. Either color may be left empty to leave that one out of the pattern.

Forces the cells to always display their content as text.

When to use it: to keep values from being reinterpreted — preserve leading zeros (00123), long codes, or anything that would otherwise turn into a number or date.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to work on. Supports @name Sheet1 No
Cell range Cell or range to format (A1, A1:C3). Supports @name A1 No

Important behavior: sets the “text” number format on each cell, so the exact characters typed are shown as-is.

When to use it: to fit long column headers by angling them, or to write text vertically.
