PDF

Output & saving

This group controls what happens when the PDF is generated: opening the finished file in a viewer, writing an extra copy to another location, reading the produced file (its bytes and size), and choosing the PDF version standard. These are final-step instructions that concern the output file rather than the content of the document.

Prerequisite: before using any of these instructions, the workflow must already have a PDF created (with Create PDF).

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used. If the document doesn’t exist (or is not a PDF), the instruction simply does nothing.
  • When these instructions take effect: every instruction in this group is recorded now and applied when the PDF is saved (when it is rendered to the final file). They don’t change the content of the document — they act on the finished .pdf.
  • Dynamic values (@name): in a text field (target path, dump path, version) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.
  • Saving a result: Save Pdf Bytes can save the produced file’s size into a named value (its Save size field). If you leave that field empty, nothing is saved. You can reuse the saved value later in the workflow (including in an @name field).
  • Open Pdf Viewer .pdf
  • Save Pdf Bytes .pdf
  • Save Pdf To File .pdf
  • Set Pdf Version .pdf

Open Pdf Viewer .pdf

Opens the generated PDF in the computer’s default PDF viewer once the document is saved.

When to use it: to automatically preview the finished PDF as soon as the workflow produces it.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No

Important behavior: this happens when the PDF is saved. It opens the file with whichever application is set as the system default for .pdf files. If the document isn’t an open PDF, nothing happens. This is the only instruction that starts another application: the workflow does not wait for the viewer and does not know whether it opened, so on a machine with no PDF viewer (or one running unattended, without a screen) the rest of the workflow finishes normally but nothing appears — leave this instruction out of workflows meant to run automatically.

Save Pdf Bytes .pdf

Reads the finished PDF when it is saved, and optionally writes a raw copy of it to another file and/or saves its size (in bytes) as a value for later use.

When to use it: to find out the exact size of the produced PDF, or to write an extra raw copy of the file to a specific path.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Dump path Full file path where a raw copy of the PDF is written. Empty = don’t write a copy. Supports @name (empty) No
Save size Name under which the file size (in bytes) is saved. Empty = don’t save (empty) No

Important behavior: this happens when the PDF is saved. If Dump path is empty, no copy is written; the copy is written to the exact path you give (no extension is added). If Save size is empty, the size is not saved.

Save Pdf To File .pdf

Copies the finished PDF to an additional file path when the document is saved.

When to use it: to also produce the PDF at a second location — for example a backup folder or a shared folder — besides its normal save path.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Target path Full path, extension included, where the extra copy is written. Supports @name output.pdf No

Important behavior: this happens when the PDF is saved. The path is used exactly as given, and an existing file at that location is overwritten. If Target path is empty, nothing happens.

Set Pdf Version .pdf

Sets the PDF version standard of the produced file.

When to use it: to target a specific PDF version for compatibility — for example an older version for older readers, or the newest version.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Pdf version PDF version standard: 1.4, 1.5, 1.6, 1.7, or 2.0. Supports @name 1.7 No

Important behavior: this is applied when the PDF is saved. Any unrecognized value falls back to 1.7.
