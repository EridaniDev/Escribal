Spreadsheet

Page setup & printing

This group of instructions controls how a spreadsheet prints (and exports to PDF): paper size, orientation and margins; which part of the sheet prints (the print area); manual page breaks; headers and footers; scaling; repeating title rows or columns; and whether gridlines and row/column headings appear on the printout. None of these change what you see on screen — they only affect the printed or exported result.

Prerequisite: before using any of these instructions, the workflow must already have an XLSX spreadsheet created or opened (with Create spreadsheet). Every instruction works on a sheet (tab) inside that spreadsheet, identified by name (Sheet1 by default), which must already exist.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used.

  • These settings affect printing only: they change how the sheet prints or exports to PDF — paper, margins, scaling, headers, and so on — not how it looks while you edit it.

  • The sheet must already exist: the Sheet name field chooses which tab the instruction works on, and defaults to Sheet1. For most instructions in this group, if no sheet with that name is found the instruction does nothing and the workflow continues with the next instruction.

  • Measurements are in centimeters: margin distances (top, bottom, left, right, header, footer) are given in centimeters.

  • Rows and columns are counted from 1: a row number like 1 means the first row; a column is given by its letter (A, B, …). Page breaks and repeating titles use these.

  • Dynamic values (@name): in any text field (sheet name, header/footer text, paper size, range, column letters, and so on) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.

  • “From variable” fields: the @name trick only works in text fields. The yes/no options (like Landscape or Show page number) and number options (like Scale or Break before) each have a companion “from variable” field:

    • If you leave it empty, the value chosen in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and reads the value from that variable.

    This is mainly for chaining instructions (one instruction saves a value, the next one reads it). If you only work with fixed values, you can ignore these fields.

Clear Print Area .xlsx

Removes the print area of a sheet, so the whole used sheet prints again.

When to use it: to undo a previously defined print area and go back to printing everything.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to clear the print area on. Supports @name Sheet1 No

Important behavior: removes the sheet’s print area if one was defined. If the sheet has no print area (or no named ranges at all), the instruction does nothing.

Delete Page Break .xlsx

Removes a manual page break that was added before a given row or column.

When to use it: to undo a page break you inserted earlier.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the break is on. Supports @name Sheet1 No
Row break On = a break before a row; off = a break before a column Yes No
Break before The row (or column) number the break sits before 10 No
Row break (from variable) Reads the row/column yes/no from a saved value (empty) No
Break before (from variable) Reads the row/column number from a saved value (empty) No

Important behavior: removes the manual break at the given position. Does nothing if Break before is 0 or negative, or if no break exists there.

Insert Page Break .xlsx

Adds a manual page break before a given row or column, forcing a new printed page.

When to use it: to control exactly where one printed page ends and the next begins.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to add the break on. Supports @name Sheet1 No
Row break On = break before a row; off = break before a column Yes No
Break before The row (or column) number the new page starts at 10 No
Row break (from variable) Reads the row/column yes/no from a saved value (empty) No
Break before (from variable) Reads the row/column number from a saved value (empty) No

Important behavior: inserts the break before the given 1-based row (when Row break is on) or column (when off). Does nothing if Break before is 0 or negative, and skips adding a duplicate break at a position that already has one.

Set Fit To Pages .xlsx

Shrinks the printout so it fits into a chosen number of pages across and down.

When to use it: to make a wide or tall sheet fit neatly onto a fixed number of pages.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to apply the fit to. Supports @name Sheet1 No
Pages wide How many pages wide the printout may use 1 No
Pages tall How many pages tall the printout may use 1 No
Pages wide (from variable) Reads the pages-wide count from a saved value (empty) No
Pages tall (from variable) Reads the pages-tall count from a saved value (empty) No

Important behavior: turns on “fit to page” and scales the sheet to fit within the given number of pages wide and tall. Use 0 for a dimension to let it use as many pages as needed in that direction. This replaces any fixed scale percentage set with Set print scale.

Set Page Footer .xlsx

Sets the footer that appears at the bottom of every printed page.

When to use it: to add a company name, file name, page number, or date to the bottom of the printout.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to set the footer on. Supports @name Sheet1 No
Left text Text shown on the left side of the footer. Supports @name (empty) No
Center text Text shown in the center of the footer. Supports @name (empty) No
Right text Text shown on the right side of the footer. Supports @name (empty) No
Show page number Add the page number to the footer Yes No
Show date Add the current date to the footer No No
Show page number (from variable) Reads the show-page-number yes/no from a saved value (empty) No
Show date (from variable) Reads the show-date yes/no from a saved value (empty) No

Important behavior: builds the footer from the left, center, and right texts. When Show page number is on, the page number is added to the center; when Show date is on, the date is added to the right (appended after any text you typed there). Replaces any existing footer.

Set Page Margins .xlsx

Sets the printing margins of a sheet, in centimeters.

When to use it: to widen or narrow the blank borders around the printed content.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to set margins on. Supports @name Sheet1 No
Top Top margin, in centimeters. -1 = leave unchanged, 0 = set to zero 1.9 No
Bottom Bottom margin, in centimeters. -1 = leave unchanged, 0 = set to zero 1.9 No
Left Left margin, in centimeters. -1 = leave unchanged, 0 = set to zero 1.8 No
Right Right margin, in centimeters. -1 = leave unchanged, 0 = set to zero 1.8 No
Header Distance from the top edge to the header, in centimeters. -1 = leave unchanged 0.8 No
Footer Distance from the bottom edge to the footer, in centimeters. -1 = leave unchanged 0.8 No
Top (from variable) Reads the top margin from a saved value (empty) No
Bottom (from variable) Reads the bottom margin from a saved value (empty) No
Left (from variable) Reads the left margin from a saved value (empty) No
Right (from variable) Reads the right margin from a saved value (empty) No
Header (from variable) Reads the header distance from a saved value (empty) No
Footer (from variable) Reads the footer distance from a saved value (empty) No

Important behavior: sets the sheet’s margins to the given values. Any margin left at -1 keeps its current value, so you can change one and leave the rest; 0 sets that margin to zero. If every margin is -1, nothing happens. The numbers are in centimeters (the program converts them internally).

Set Page Orientation .xlsx

Chooses whether the sheet prints in portrait or landscape.

When to use it: to switch a wide sheet to landscape so more columns fit across the page.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to set orientation on. Supports @name Sheet1 No
Landscape On = landscape (wide); off = portrait (tall) No No
Landscape (from variable) Reads the landscape yes/no from a saved value (empty) No

Important behavior: sets the page orientation to landscape when Landscape is on, or portrait when off.

Set Paper Size .xlsx

Chooses the paper size used when printing the sheet.

When to use it: to print on a specific paper size, such as Letter or A3.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to set the paper size on. Supports @name Sheet1 No
Paper size Chosen from a list: A4, A3, A5, B4, B5, Letter, Legal, Tabloid A4 No

Important behavior: the paper size is picked from a list, so it cannot be typed freely and does not accept @name. A workflow saved with an older, unlisted value still prints on A4.

Set Print Area .xlsx

Defines which range of cells prints, ignoring everything outside it.

When to use it: to print only a specific block of the sheet (for example a summary table) and leave out the rest.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to set the print area on. Supports @name Sheet1 No
Range address The range to print, as two corners (A1 style). Supports @name A1:Z100 No

Important behavior: sets the print area to the given range; any earlier print area on that sheet is replaced. If the sheet does not exist, the instruction simply does nothing.

Set Print Scale .xlsx

Scales the printout to a fixed percentage of its normal size.

When to use it: to shrink or enlarge the printed sheet by a set percentage.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to apply the scale to. Supports @name Sheet1 No
Scale Print size as a percentage (10 to 400) 100 No
Scale (from variable) Reads the scale percentage from a saved value (empty) No

Important behavior: sets a fixed print scale, kept between 10% and 400%. Using a fixed scale turns off “fit to page”, so this replaces any Set fit to pages setting.

Set Print Title Columns .xlsx

Repeats one or more columns on every printed page.

When to use it: to keep a label column (for example row headers on the left) visible on every page of a wide printout.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to apply this to. Supports @name Sheet1 No
First column The first column letter to repeat. Supports @name A No
Last column The last column letter to repeat. Supports @name A No

Important behavior: repeats the columns from First column to Last column on every printed page. It keeps any repeating title rows already set (see Set print title rows). If the sheet does not exist, the instruction does nothing.

Set Print Title Rows .xlsx

Repeats one or more rows on every printed page.

When to use it: to keep a header row (for example column titles at the top) visible on every page of a long printout.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to apply this to. Supports @name Sheet1 No
First row The first row number to repeat 1 No
Last row The last row number to repeat 1 No
First row (from variable) Reads the first row number from a saved value (empty) No
Last row (from variable) Reads the last row number from a saved value (empty) No
