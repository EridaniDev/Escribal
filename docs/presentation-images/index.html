Presentation

Images

This group of instructions adds and manages images on a slide: inserting a picture from a file, dropping one into a slide placeholder, and replacing an image with a different file. It also lets you adjust an image already on a slide — resize it, reposition it, crop its edges, make it partly transparent, or add a border around it.

Prerequisite: before using any of these instructions, the workflow must already have a PPTX presentation created or opened (with Create presentation), which these instructions will act upon.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used.

  • Slide numbers start at 1: slides are referred to by their position, and the first slide is 1, the second is 2, and so on. The Slide number field uses this numbering.

  • Out-of-range slide numbers do nothing: if the slide number does not exist in the presentation (for example, slide 5 in a 3-slide deck), the instruction does nothing and the workflow continues with the next instruction.

  • Images are identified by their name: Insert Image From File gives each inserted image an automatic name (for example Image5) and can save it for you with Save image name in. Every instruction that changes an existing image (Resize Image, Reposition Image, Crop Image, Set Image Transparency, Apply Border To Image, Replace Image) finds the image to act on by that name, and acts on every image with that name. If the Image name is left empty, the instruction applies to all the images on the slide; if no image with that name exists on the slide, nothing happens. (Insert Image Into Placeholder is the exception: it locates the target by its placeholder position, not by an image name.)

  • Measurements and colors: positions and sizes are given in centimeters (cm); crop amounts and transparency in percent; border thickness in points (pt); colors as hex codes (for example 000000), with or without a leading #.

  • Dynamic values (@name): in any text field you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value. For example, if you saved a file path in logoPath, you can type @logoPath in the Image file path field.

  • Saving a result: Insert Image From File offers a Save image name in field that stores the inserted image’s name under a name you choose, so you can reuse it later in the Image name field of the other instructions. If left empty, nothing is saved.

  • “From variable” fields: the @name trick only works in text fields. So that a numeric field (like Slide number or Width (cm)) can also take its value from a saved value, each one has a companion “from variable” field:

    • If you leave it empty, the value typed in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and uses that variable’s value.

    This is mainly for chaining instructions (one instruction saves a value, the next one reads it). If you only work with fixed values, you can ignore these fields.

Apply Border To Image .pptx

Adds a border line around an image on a slide.

When to use it: to frame a picture with a colored outline.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the image is on (starts at 1) 1 No
Image name Name of the images to border; empty = every image on the slide. Supports @name (empty) No
Color Border color as a hex code (for example 000000). Supports @name 000000 (black) No
Thickness (pt) Border thickness in points 1 No
Line style solid, dash, dot, or dashdot. Supports @name solid No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Thickness (from variable) Reads the thickness from a saved value (empty) No

Important behavior: if Image name is empty the border is applied to every image on the slide; if no image with that name is found, nothing happens. An unrecognized Line style falls back to solid. Any existing border on the image is replaced. The color may be written with or without a leading #; leaving it empty draws the border with its thickness and style but without setting a colour, so it takes the presentation theme’s line colour.

Crop Image .pptx

Trims the edges of an image by a percentage, without changing the file.

When to use it: to hide unwanted borders or focus on part of a picture.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the image is on (starts at 1) 1 No
Image name Name of the images to crop; empty = every image on the slide. Supports @name (empty) No
Crop left (%) Percentage trimmed from the left edge 0 No
Crop top (%) Percentage trimmed from the top edge 0 No
Crop right (%) Percentage trimmed from the right edge 0 No
Crop bottom (%) Percentage trimmed from the bottom edge 0 No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Crop left (from variable) Reads the left crop from a saved value (empty) No
Crop top (from variable) Reads the top crop from a saved value (empty) No
Crop right (from variable) Reads the right crop from a saved value (empty) No
Crop bottom (from variable) Reads the bottom crop from a saved value (empty) No

Important behavior: if Image name is empty every image on the slide is cropped; if no image with that name is found, nothing happens. Cropping hides part of the image — it does not resize the frame on the slide.

Delete Image .pptx

Removes an image from a slide.

When to use it: to drop a logo or a picture that a later step replaces with another one.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide to act on, counting from 1 1 No
Image name Name of the image to remove. Supports @name (empty) Yes
Slide number (from variable) Reads the slide from a saved value (empty) No
Save count key Name to save how many were removed under (empty) No

Important behavior: the name is required; with it empty the instruction does nothing. Only images are removed: a shape that happens to have the same name is left alone. The picture file inside the presentation is kept, because another slide may still be showing it.

Insert Image From File .pptx

Inserts a picture from a file on your computer onto a slide.

When to use it: to add a logo, photo, or any local image to a slide.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide to place the image on (starts at 1) 1 No
Image file path Full path to the image file. Supports @name (empty) Yes
Left (cm) Distance from the left edge of the slide 2 No
Top (cm) Distance from the top edge of the slide 2 No
Width (cm) Image width in centimeters 8 No
Height (cm) Image height in centimeters 6 No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Left (from variable) Reads the left position from a saved value (empty) No
Top (from variable) Reads the top position from a saved value (empty) No
Width (from variable) Reads the width from a saved value (empty) No
Height (from variable) Reads the height from a saved value (empty) No
Save image name in Name under which to save the inserted image’s name (empty) No

Important behavior: if the path is empty, nothing happens. The image is given an automatic name (such as Image5) which you can save with Save image name in and later reuse in the other instructions. JPEG, GIF, BMP, and TIFF files are recognized by their extension; any other extension is treated as PNG.

Insert Image Into Placeholder .pptx

Inserts a picture into one of a slide’s picture placeholders (the empty image frames defined by the slide’s layout).

When to use it: to fill a layout’s picture placeholder so the image sits and sizes exactly where the layout intends.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the placeholder is on (starts at 1) 1 No
Placeholder number Which picture placeholder to fill, counting picture/object placeholders on the slide from 1 1 No
Image file path Full path to the image file. Supports @name (empty) Yes
Slide number (from variable) Reads the slide number from a saved value (empty) No
Placeholder number (from variable) Reads the placeholder number from a saved value (empty) No
Save image name in Name under which to save the placed image’s name (empty) No

Important behavior: if the path is empty, nothing happens. The Placeholder number counts only picture/object placeholders, in the order they appear on the slide, starting at 1; if it is out of range, nothing happens. It works whether the chosen placeholder is still empty or already holds an image (in which case the old image is replaced).

Replace Image .pptx

Replaces an existing image on a slide with a different file, keeping its position and size.

When to use it: to swap a placeholder photo for the final one without re-inserting and re-positioning it.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the image is on (starts at 1) 1 No
Image name Name of the images to replace; empty = every image on the slide. Supports @name (empty) No
New image path Full path to the replacement image file. Supports @name (empty) Yes
Slide number (from variable) Reads the slide number from a saved value (empty) No

Important behavior: if New image path is empty, nothing happens. If Image name is empty every image on the slide is replaced with that file; if no image with that name is found, nothing happens. The old image is removed from the file and the new one takes its place and frame.

Reposition Image .pptx

Moves an image to a new position on the slide.

When to use it: to line up an image at a precise spot after inserting it.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the image is on (starts at 1) 1 No
Image name Name of the images to move; empty = every image on the slide. Supports @name (empty) No
Left (cm) New distance from the left edge of the slide 2 No
Top (cm) New distance from the top edge of the slide 2 No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Left (from variable) Reads the left position from a saved value (empty) No
Top (from variable) Reads the top position from a saved value (empty) No

Important behavior: if Image name is empty every image on the slide is moved to that position; if no image with that name is found, nothing happens.

Resize Image .pptx

Changes the width and height of an image on the slide.

When to use it: to make an image bigger or smaller after inserting it.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the image is on (starts at 1) 1 No
Image name Name of the images to resize; empty = every image on the slide. Supports @name (empty) No
Width (cm) New width in centimeters 8 No
Height (cm) New height in centimeters 6 No
Keep aspect ratio Yes = compute the height from the width to keep the image’s proportions No No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Width (from variable) Reads the width from a saved value (empty) No
Height (from variable) Reads the height from a saved value (empty) No
Keep aspect ratio (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: if Image name is empty every image on the slide is resized; if no image with that name is found, nothing happens. When Keep aspect ratio is Yes, the height is calculated from the width to preserve the original proportions and the Height field is ignored.

Set Image Opacity .pptx

Makes an image partly see-through, or restores it to fully opaque.

When to use it: to fade a background image, or to soften a picture placed behind text.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the image is on (starts at 1) 1 No
Image name Name of the images to make transparent; empty = every image on the slide. Supports @name (empty) No
Opacity (%) How opaque the image is: 100 = fully opaque, lower = more see-through 100 No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Opacity (from variable) Reads the opacity from a saved value (empty) No

Important behavior: if Image name is empty every image on the slide is affected; if no image with that name is found, nothing happens. An Opacity of 100 or more removes any transparency (fully opaque); values below 100 make the image see-through. The value is limited to the range 0–100.
