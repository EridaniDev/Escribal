Tables

This group of instructions creates and edits tables on a slide: inserting a new table, adding or removing rows and columns, writing and formatting the contents of a cell, merging cells, adjusting column widths and row heights, and applying a predefined table style.

Prerequisite: before using any of these instructions, the workflow must already have a PPTX presentation created or opened (with Create presentation), which these instructions will act upon.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used.

  • Slide numbers start at 1: slides are referred to by their position, and the first slide is 1, the second is 2, and so on. The Slide number field uses this numbering.

  • Out-of-range slide numbers do nothing: if the slide number does not exist in the presentation (for example, slide 5 in a 3-slide deck), the instruction does nothing and the workflow continues with the next instruction.

  • Tables are identified by their name: Insert Table gives the new table a name (by default Table1). Every other instruction in this group finds the tables to act on by that name and applies to every table with it. Leaving the Table name empty applies the instruction to all tables on the slide. If the name matches no table, the instruction does nothing. If you create several tables on the same slide, give each a distinct name so the later instructions can target the right one.

  • Rows and columns start at 1: cells, rows, and columns are referred to by position, with the first one being 1. So the top-left cell is row 1, column 1.

  • Measurements and colors: positions, sizes, widths, and heights are given in centimeters (cm); border and font thickness/size in points (pt); colors as hex codes (for example 000000), with or without a leading #.

  • Dynamic values (@name): in any text field you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value. For example, if you saved a cell text in heading, you can type @heading in the Text field.

  • Saving a result: the row- and column-changing instructions offer a Save row count in / Save column count in field that stores the table’s new row or column count under a name you choose, so you can reuse it later. If left empty, nothing is saved.

  • “From variable” fields: the @name trick only works in text fields. So that a numeric field (like Slide number or Width (cm)) or a yes/no field (like Bold) can also take its value from a saved value, each one has a companion “from variable” field:

    • If you leave it empty, the value typed in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and uses that variable’s value.

    This is mainly for chaining instructions (one instruction saves a value, the next one reads it). If you only work with fixed values, you can ignore these fields.

  • Nothing happens if the document is missing: if the Document refers to a presentation that is not open, the instruction simply does nothing (no error).

Add Column To Table .pptx

Adds a new empty column to an existing table.

When to use it: to extend a table with an extra column after it has been created.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the table is on (starts at 1) 1 No
Table name Name of the tables to change; empty = all tables on the slide. Supports @name Table1 No
Insert at number Column position to insert before (starts at 1); -1 = add at the end -1 No
Column width (cm) Width of the new column 4 No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Insert at number (from variable) Reads the position from a saved value (empty) No
Column width (from variable) Reads the width from a saved value (empty) No
Save column count in Name under which to save the table’s new column count (empty) No

Important behavior: if no table with that name is found, nothing happens. When Insert at number is -1 or beyond the last column, the new column is added at the end; otherwise it is inserted before the given position. A new empty cell is added to every row.

When to use it: to give a table a professional look in one step, choosing whether the header row, banded rows, and first column stand out.

Sets the fill color and border of a single table cell.

When to use it: to highlight a cell with a background color, or to add or remove its borders.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the table is on (starts at 1) 1 No
Table name Name of the tables to change; empty = all tables on the slide. Supports @name Table1 No
Row number Row of the cell (starts at 1) 1 No
Column number Column of the cell (starts at 1) 1 No
Fill color Background color as a hex code; empty = no fill (transparent). Supports @name (empty) No
Border color Border color as a hex code. Supports @name 000000 (black) No
Border thickness (pt) Border line thickness in points 1 No

Slide number (from variable) Reads the slide number from a saved value (empty) No
Row number (from variable) Reads the row number from a saved value (empty) No
Column number (from variable) Reads the column number from a saved value (empty) No
Border thickness (from variable) Reads the thickness from a saved value (empty) No
No border (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: if no table with that name is found, or the row/column is out of range, nothing happens. Any existing fill and borders on the cell are replaced. When Fill color is empty, the cell is left transparent (no fill); otherwise it is filled with that color.

Format Cell Text .pptx

Formats the text already written in one cell of a table: bold, italic, underline, color, typeface, and size.

When to use it: to highlight the header row or a figure after filling the table with Set Cell Content. Format Cell paints the cell itself — fill and borders; this one is about the text inside it.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide that holds the table (starts at 1) 1 No
Table name Name of the table on the slide. Supports @name Table1 No
Row number Row of the cell (starts at 1) 1 No
Column number Column of the cell (starts at 1) 1 No
Bold true turns it on, false turns it off, empty leaves it as it is (empty) No
Italic true turns it on, false turns it off, empty leaves it as it is (empty) No
Underline true turns it on, false turns it off, empty leaves it as it is (empty) No
Color hex Text color, 6 hex digits without #. Empty = no change. Supports @name (empty) No
Font name Typeface of the text. Empty = no change. Supports @name (empty) No
Font size pt Size in points. 0 = no change 0 No
Slide number (from variable) Reads the slide position from a saved value (empty) No
Row number (from variable) Reads the row position from a saved value (empty) No
Column number (from variable) Reads the column position from a saved value (empty) No
Font size pt (from variable) Reads the size from a saved value (empty) No

Important behavior: the format travels with the text, so a cell with no text yet has nothing to format — write it first with Set Cell Content. Every attribute left empty (or 0) is left as it is, so several calls stack up. If several tables on the slide share the name, all of them are formatted; a slide, table, row, or column that doesn’t exist is not an error: the instruction does nothing.

Iterate Rows .pptx

Publishes the rows of a table on a slide into a variable, so a For Each can walk them one by one.

When to use it: to read a table that is already on a slide and do something per row.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide that holds the table (starts at 1) 1 No
Table name Name of the table on the slide. Supports @name Table1 No
Use first row as header Yes: the first row names the fields and is not a turn. No: the fields are column1, column2… and every row is a turn true No
Slide number (from variable) Reads the slide position from a saved value (empty) No
Use first row as header (from variable) Reads that yes/no from a saved value (empty) No
Save key Name of the variable that receives the rows. Empty = the instruction does nothing useful (empty) No
Save count key Name of the variable that receives how many rows there are (empty) No

If several tables on the slide share the name, the turns come from the first one: a loop cannot walk two tables at once (unlike the formatting instructions, which do apply to all of them).

Important behavior: the turns are a copy taken when the instruction runs: what the loop walks does not change if the body edits the document. To leave a result back in the row, write it by position — the Index of the For Each feeds the “(from variable)” field of the writing instruction. In this format that instruction is Set Cell Content, whose Row number (from variable) takes the loop’s index.

Set Column Width Or Row Height .pptx

Sets the width of a column, the height of a row, or both, in a table.

When to use it: to make a specific column wider or a specific row taller after the table is created.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the table is on (starts at 1) 1 No
Table name Name of the tables to change; empty = all tables on the slide. Supports @name Table1 No
Column number Column to resize (starts at 1); -1 = every column -1 No
Column width (cm) New width for that column; -1 = leave the widths as they are 4 No
Row number Row to resize (starts at 1); -1 = every row -1 No
Row height (cm) New height for that row; -1 = leave the heights as they are 1.5 No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Column number (from variable) Reads the column number from a saved value (empty) No
Column width (from variable) Reads the width from a saved value (empty) No
Row number (from variable) Reads the row number from a saved value (empty) No
Row height (from variable) Reads the height from a saved value (empty) No

Important behavior: if no table with that name is found, nothing happens. The two axes work the same way as everywhere else in the app: -1 in an index means “every one” (every column, every row) and -1 in a measurement means “leave that one as it is”. So to resize only columns, set Row height to -1; to make every column the same width, leave Column number at -1. With the default values the instruction sets every column to 4 cm and every row to 1.5 cm. If the chosen index is beyond the table’s range, that change is skipped.
