Spreadsheet

Tables

This group creates and manages structured tables in a spreadsheet. A table is the special “formatted table” object — a named range with a header row, banded rows and filter arrows — as opposed to a plain block of cells. This group can turn a range into a table, rename or delete it, add and remove columns, append data rows, show a totals row with per-column calculations, restyle it, toggle the row/column banding, and turn the filter arrows on or off.

Prerequisite: before using any of these instructions, the workflow must already have an XLSX spreadsheet created or opened (with Create spreadsheet). Every instruction works on a sheet (tab) inside that spreadsheet, identified by name (Sheet1 by default), which must already exist. Create Table turns an existing range of cells into a table; every other instruction here needs a table that already exists, identified by its name.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used. If the document doesn’t exist, the instruction simply does nothing.

  • The sheet must already exist: the Sheet name field chooses which tab the instruction works on, and defaults to Sheet1. If no sheet with that name is found, the instruction simply does nothing and the rest of the workflow carries on.

  • Table name: every instruction identifies its table by name (Table1 by default). Table names must be unique across the whole workbook: Create Table and Rename Table refuse to produce a duplicate name (they do nothing in that case). If an instruction can’t find a table with the given name on the sheet, it simply does nothing.

  • Cell addresses and ranges: cells are written in A1 style (a column letter plus a row number, like B2). Create Table takes the range as two corners — a Start cell (top-left) and an End cell (bottom-right), for example A1 to D10.

  • Columns are counted from 1: where an instruction takes a column position or Column number, the first column of the table is 1, the second 2, and so on — the same way a spreadsheet numbers rows and columns — and the same way charts, images and shapes are numbered in their own groups. Delete Column From Table accepts either a column name or a position, which is useful for tables without headers; Add Column To Table appends at the end when the position is outside the table.

  • Dynamic values (@name): in any text field (sheet name, table name, column name, cell address, row values…) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.

  • Save a result (Save …): Add Rows To Table can store how many rows it added under a name you choose (Save rows added), so a later instruction can reuse it. Leaving the field empty saves nothing.

  • “From variable” fields: the @name trick only works in text fields. The numeric fields (like Position, Column number, Repeat count) and the yes/no fields (like Has headers, Show, Enabled, Row stripes) each have a companion “from variable” field:

    • If you leave it empty, the value chosen in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and reads the value from that variable.

    This is mainly for chaining instructions — for example, adding as many rows as a count computed earlier. If you only work with fixed values, you can ignore these fields.

Add Column To Table .xlsx

Adds a new column to a table, at the end or at a chosen position.

When to use it: to grow a table with an extra field after it has been created.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to change. Supports @name Table1 No
Column name Header text for the new column. Supports @name NewColumn No
Position Where to insert it (1 = first column); -1 or a value past the last column adds it at the right end -1 No
Position (from variable) Reads the position from a saved value (empty) No

Important behavior: the table’s range grows by one column to include the new one. Only the column header is added — the cells below it start empty. If the table isn’t found, or its stored range is invalid, nothing happens.

Add Rows To Table .xlsx

Appends one or more data rows to the bottom of a table.

When to use it: to feed records into a table, one row at a time or several identical rows at once.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to add to. Supports @name Table1 No
Row values The cell values for the row, separated by the column separator. Supports @name Value1, Value2, Value3 No
Column separator The character that separates the values , No
Repeat count How many rows to add (all with the same values) 1 No
Repeat count (from variable) Reads the number of rows from a saved value (empty) No
Save rows added Name under which to store how many rows were added (empty) No

Important behavior: each new row is added below the last data row and the table’s range grows to include it. Values that look like numbers are stored as numbers, everything else as text. If the table shows a totals row, the new rows are inserted above it. Extra values beyond the table’s columns are ignored; if you supply fewer values than columns, the remaining cells are left empty. If Column separator is empty, nothing happens; a Repeat count below 1 is treated as 1.

Apply Table Style .xlsx

Changes the visual style of a table and whether the first/last columns are emphasized.

When to use it: to restyle an existing table without recreating it.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to restyle. Supports @name Table1 No
Table style Name of a built-in table style TableStyleMedium9 No
Show first column Yes = emphasize the first column No No
Show last column Yes = emphasize the last column No No
Show first column (from variable) Reads the setting from a saved value (empty) No
Show last column (from variable) Reads the setting from a saved value (empty) No

Important behavior: common style names are TableStyleLight1–21, TableStyleMedium1–28, TableStyleDark1–11, or None for no style. If the table isn’t found, nothing happens.

Create Table .xlsx

Turns a range of cells into a structured table with a header row, an auto-filter and row banding.

When to use it: the starting point — run it once to convert a block of data into a table that the other instructions in this group can then manage.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab that holds the range. Supports @name Sheet1 No
Start cell Top-left corner of the range (A1 style). Supports @name A1 No
End cell Bottom-right corner of the range (A1 style). Supports @name D10 No
Table name Name for the new table (must be unique). Supports @name Table1 No
Table style Name of a built-in table style TableStyleMedium9 No
Has headers Yes = the first row of the range holds the column names Yes No
Has headers (from variable) Reads the setting from a saved value (empty) No

Important behavior: if Table name is empty, or a table with that name already exists anywhere in the workbook, nothing happens. If the range is invalid (for example the start is below or right of the end), nothing happens. When Has headers is Yes, the text in the first row becomes the column names; otherwise the columns are named Column1, Column2, … The new table gets filter arrows and row banding by default. If the sheet doesn’t exist, the instruction does nothing.

Delete Column From Table .xlsx

Removes a column from a table, by name or by position.

When to use it: to drop a field you no longer need from a table.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to change. Supports @name Table1 No
Column name Name of the column to remove (takes priority). Supports @name (empty) No
Column number Position of the column to remove (1 = first), used when Column name is empty -1 No
Column number (from variable) Reads the position from a saved value (empty) No

Important behavior: the column is found by name first (case-insensitive); if Column name is empty, it is found by position instead. If neither matches a column, nothing happens. The table’s range shrinks by one column.

Delete Table .xlsx

Removes the table definition but keeps the cell data.

When to use it: to convert a table back into an ordinary range of cells without losing the values.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to remove. Supports @name Table1 No

Important behavior: only the table object is removed — the data stays in the cells as a plain range. If no table with that name is on the sheet, nothing happens.

Rename Table .xlsx

Changes a table’s name.

When to use it: to give a table a clearer name (for example after creating it with the default Table1).

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Current name The table’s current name. Supports @name Table1 No
New name The new name for the table. Supports @name SalesData No

Important behavior: if New name is empty, nothing happens. Table names must be unique, so if a table with the new name already exists in the workbook, nothing happens. If the current table isn’t found, nothing happens.

Set Table Auto Filter .xlsx

Shows or hides the filter dropdown arrows on a table’s header row.

When to use it: to let users filter and sort the table from its header, or to remove those arrows for a cleaner look.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to change. Supports @name Table1 No
Enabled Yes = show the filter arrows, No = remove them Yes No
Enabled (from variable) Reads the setting from a saved value (empty) No

Important behavior: turning it on adds the filter arrows across the table’s current range; turning it off removes them. If the table isn’t found, nothing happens.

Set Table Banding .xlsx

Toggles the alternating row or column shading (banding) of a table.

When to use it: to make a table easier to read with striped rows, or to add column stripes instead.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to change. Supports @name Table1 No
Row stripes Yes = shade every other row Yes No
Column stripes Yes = shade every other column No No
Row stripes (from variable) Reads the setting from a saved value (empty) No
Column stripes (from variable) Reads the setting from a saved value (empty) No

Important behavior: the exact colors come from the table’s current style. If the table isn’t found, nothing happens.

Set Totals Row .xlsx

Shows or hides a totals row at the bottom of a table, and optionally sets a calculation for each column.

When to use it: to add a summary line (sums, averages, counts…) under a table.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab the table is on. Supports @name Sheet1 No
Table name The table to change. Supports @name Table1 No
Show Yes = show the totals row, No = hide it Yes No
Column functions Per-column calculations, as comma-separated Column:Function pairs. Supports @name (empty) No
Show (from variable) Reads the setting from a saved value (empty) No

Important behavior: Column functions takes pairs like Price:Sum, Quantity:Count. The available functions are None, Sum, Min, Max, Average, Count, CountNums, StdDev and Var (a column not listed gets no total). Showing the totals row adds one row at the bottom of the table; hiding it removes that row and clears every column’s function. If the table isn’t found, nothing happens.
