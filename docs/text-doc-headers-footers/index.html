Text Doc

Headers & footers

This group of instructions manages the headers and footers of a document — the repeating text that appears at the top and bottom of every page. You can write header and footer text, use different headers/footers on the first page or on even/odd pages, link a section’s header/footer to the previous section, and set how far they sit from the page edge.

Prerequisite: before using any of these instructions, the workflow must already have a DOCX document created or opened (with Create text doc), which these instructions will act upon.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used.

  • Dynamic values (@name): in any text field (such as Text or Font) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value. For example, if you saved a title in reportTitle, you can type @reportTitle in the Text field.

  • Which pages (Page type): several instructions ask which pages the header or footer applies to:

    • default — all pages (this is the normal case).
    • first — only the first page (works together with Set Different First Page).
    • even — only even-numbered pages (works together with Set Different Even Odd Pages).

  • “From variable” fields: the @name trick only works in text fields. So that a numeric field (like Font size or Section number) can also take its value from a saved value, those fields have a companion “from variable” field:

    • If you leave it empty, the value typed in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and uses that variable’s value.

    This is mainly for chaining instructions (one instruction saves a value, a later one reads it). If you only work with fixed values, you can ignore these fields.

Insert Footer .docx

Adds or replaces the footer — the text shown at the bottom of the pages. You can target all pages, or only the first or even pages, give the text basic formatting (bold, italic, font, size, alignment), and add an automatic field after it, such as the page number.

When to use it: to put a page footer such as a document title, a confidential notice, or company details at the bottom of every page.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Text The footer text. Supports @name (empty) No
Field Automatic field written after the text: none, PAGE (page number), PAGEOFTOTAL (page number and total pages), NUMPAGES, SECTIONPAGES, DATE, TIME, CREATEDATE, SAVEDATE, PRINTDATE, AUTHOR, LASTSAVEDBY, FILENAME, TITLE, SUBJECT none (no field) No
Separator Text shown between the page number and the total; only used by PAGEOFTOTAL. Supports @name " of " No
Page type Which pages it applies to: default (all), first, even default (all pages) No
Bold Whether the text is bold No No
Italic Whether the text is italic No No
Font Font name for the text (empty = keep the default). Supports @name (empty) No
Font size Font size in points (0 = keep the default size) 0 No
Align text Text alignment: left, center, right, or justify left No
Bold (from variable) Reads the yes/no value from a saved value (empty) No
Italic (from variable) Reads the yes/no value from a saved value (empty) No
Font size (from variable) Reads the font size from a saved value (empty) No

Important behavior: this replaces any existing footer of the same page type across every section — the old footer is removed and the new one takes its place. The font is only applied when Font is not empty, and the size only when Font size is greater than 0.

Page numbers: Field writes an automatic field after the text, so a footer can read “Page 3 of 12”: put Page in Text, choose PAGEOFTOTAL and leave the separator as " of ". The number updates by itself as the document repaginates; until the word processor refreshes it, a placeholder such as [PAGE] may be shown in its place. Separator is only used by PAGEOFTOTAL, and the field takes the same formatting (bold, italic, font, size) as the footer text.

Link To Previous Section .docx

Links or unlinks a section’s header or footer to the one in the previous section. When linked, the section inherits the header/footer from the section before it; when unlinked, the section gets its own independent header/footer.

When to use it: in a document split into sections, to decide whether each section repeats the previous section’s header/footer or defines a different one.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Zone Which one to link: header or footer header No
Page type Which pages it applies to: default (all), first, even default (all pages) No
Link Yes = inherit from the previous section; No = define its own Yes (linked) No
Section number Which section to act on, counting from 1 (1 = the first) 1 No
Link (from variable) Reads the yes/no value from a saved value (empty) No
Section number (from variable) Reads the section number from a saved value (empty) No

Important behavior: if the chosen Section number does not exist, nothing happens. With Link set to Yes, the section’s own header/footer of that page type is removed so it inherits from the previous section; with Link set to No, an empty independent header/footer is created if the section did not already have one.

Remove Footer .docx

Removes the footer of a page type

When to use it: to take out a footer with page numbers or a legal note before delivering the document.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Page type default (all pages) · first · even. Supports @name default No
Save count key Name to save how many were removed under (empty) No

Important behavior: only the footer of the chosen page type is removed. If the document has none, nothing happens and the count is saved as 0.

Remove Header .docx

Removes the header of a page type

When to use it: to take the header off a document that was opened with one, or to undo a header added earlier in the workflow.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Page type default (all pages) · first · even. Supports @name default No
Save count key Name to save how many were removed under (empty) No

Important behavior: only the header of the chosen page type is removed. If the document has none, nothing happens and the count is saved as 0. The content of the pages is not touched.

Set Different Even Odd Pages .docx

Turns on or off the use of different headers and footers on even and odd pages. This is a document-wide setting that affects all sections.

When to use it: for book-style layouts where left (even) and right (odd) pages should carry different headers or footers — for example, the book title on one side and the chapter title on the other.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Enable Yes to use different even/odd headers and footers, No to use the same on all pages Yes (enabled) No
Enable (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: this only switches the option on or off; you still define the actual even-page text with Insert Header / Insert Footer using Page type even.

Set Different First Page .docx

Turns on or off a distinct header and footer on the first page of each section.

When to use it: when the first page should look different from the rest — for example, a cover page with no header, or a special footer only on page one.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Enable Yes to give the first page its own header/footer, No to use the same as the other pages Yes (enabled) No
Enable (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: this only switches the option on or off; you still define the actual first-page text with Insert Header / Insert Footer using Page type first.

Set Header Footer Margin .docx

Sets the distance, in centimetres, between the header or footer and the edge of the page. Applies to all sections in the document.

When to use it: to move the header or footer closer to or farther from the page edge, for example to fit a taller logo or comply with a print margin.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Header distance (cm) Distance from the top edge to the header, in centimetres (-1 = leave unchanged) -1 (unchanged) No
Footer distance (cm) Distance from the bottom edge to the footer, in centimetres (-1 = leave unchanged) -1 (unchanged) No
Header distance (from variable) Reads the header distance from a saved value (empty) No
Footer distance (from variable) Reads the footer distance from a saved value (empty) No

Important behavior: each distance is only changed when its value is 0 or greater; a value of -1 leaves that distance untouched, so you can set just the header, just the footer, or both.
