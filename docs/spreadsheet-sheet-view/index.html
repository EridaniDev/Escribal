Spreadsheet

Sheet view

This group controls how a sheet is displayed and navigated — the zoom level, gridlines, row and column headers, frozen panes (splits), the selected cell, and outline (grouping) levels. These are view settings: they change how the sheet looks and behaves when it is opened, not the data inside it.

Prerequisite: before using any of these instructions, the workflow must already have an XLSX spreadsheet created or opened (with Create spreadsheet). Every instruction works on a sheet (tab) inside that spreadsheet, identified by name (Sheet1 by default), which must already exist.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used. If the document doesn’t exist, the instruction simply does nothing.

  • The sheet must already exist: the Sheet name field chooses which tab the instruction works on, and defaults to Sheet1. If no sheet with that name is found, the instruction simply does nothing and the rest of the workflow carries on.

  • Dynamic values (@name): in a text field (sheet name, cell reference) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.

  • “From variable” fields: the @name trick only works in text fields. The numeric fields (Zoom percent, Split columns, Split rows, Row level, Column level) and the yes/no fields (Show grid lines, Show headers, Show outline symbols) each have a companion “from variable” field:

    • If you leave it empty, the value chosen in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and reads the value from that variable.

    This is mainly for chaining instructions. If you only work with fixed values, you can ignore these fields.

Remove Pane Split .xlsx

Removes any frozen panes or split on the sheet and returns to a single, normal view.

When to use it: to undo a Split Sheet Into Panes and unfreeze the sheet.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to act on. Supports @name Sheet1 No

Important behavior: the selected cell is reset to A1. If the sheet has no view settings yet (nothing was ever split or frozen), nothing happens.

Set Active Cell .xlsx

Sets the selected (active) cell — the cell that is highlighted when the sheet is opened.

When to use it: to make the sheet open with the cursor on a specific cell.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to act on. Supports @name Sheet1 No
Cell reference The cell to select, in A1 style (e.g. B5). Supports @name A1 No

Important behavior: if Cell reference is empty, nothing happens. If the sheet is split into panes, the selection is applied to the active pane.

Set Grid Lines Visible .xlsx

Shows or hides the gridlines (the faint lines between cells) in the sheet view.

When to use it: to hide gridlines for a cleaner, report-style look.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to act on. Supports @name Sheet1 No
Show grid lines Yes = show the gridlines Yes No
Show grid lines (from variable) Reads the setting from a saved value (empty) No

Important behavior: this affects only the on-screen gridlines, not printed gridlines (those are controlled in Page setup & printing).

Set Outline Level .xlsx

Sets the outline (grouping) level shown for rows and/or columns, and whether the outline expand/collapse buttons are visible.

When to use it: to control how grouped (outlined) rows or columns appear when the sheet opens.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to act on. Supports @name Sheet1 No
Row level Outline level for rows, 0–8. -1 = leave unchanged -1 No
Column level Outline level for columns, 0–8. -1 = leave unchanged -1 No
Show outline symbols Yes = show the group expand/collapse buttons Yes No
Row level (from variable) Reads the value from a saved value (empty) No
Column level (from variable) Reads the value from a saved value (empty) No
Show outline symbols (from variable) Reads the setting from a saved value (empty) No

Important behavior: Row level and Column level are only applied when they are between 0 and 8; any other value (including the default -1) leaves that setting unchanged. This sets the summary outline level for the sheet — it does not group the rows or columns by itself.

Set Row And Column Headers Visible .xlsx

Shows or hides the row and column headers — the A B C… and 1 2 3… labels along the edges of the sheet.

When to use it: to hide the headers for a cleaner presentation view.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to act on. Supports @name Sheet1 No
Show headers Yes = show the row and column headers Yes No
Show headers (from variable) Reads the setting from a saved value (empty) No

Important behavior: this hides only the on-screen header labels; the cells and their addresses are unchanged.

Set Zoom Level .xlsx

Sets the zoom level of the sheet view, as a percentage.

When to use it: to make the sheet open zoomed in or out.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to act on. Supports @name Sheet1 No
Zoom percent Zoom as a percentage (50–400) 100 No
Zoom percent (from variable) Reads the value from a saved value (empty) No

Important behavior: the value is clamped to the 50–400 range — anything lower becomes 50, anything higher becomes 400.

Split Sheet Into Panes .xlsx

Freezes panes by splitting the sheet after a number of columns and/or rows, so those columns and rows stay in view while the rest scrolls.

When to use it: to keep header rows or label columns visible as the user scrolls.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Sheet name Tab to act on. Supports @name Sheet1 No
Split columns Number of columns to freeze from the left 0 No
Split rows Number of rows to freeze from the top 0 No
Split columns (from variable) Reads the value from a saved value (empty) No
Split rows (from variable) Reads the value from a saved value (empty) No

Important behavior: you can freeze columns, rows, or both. If both Split columns and Split rows are 0 (or negative), nothing happens. Applying a new split replaces any previous split on the sheet. To remove it, use Remove Pane Split.
