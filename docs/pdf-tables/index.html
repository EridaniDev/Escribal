PDF

Tables

This group builds and formats tables in a PDF: inserting a table, adding rows, filling cells with text or images, and styling them (widths, borders, background, alignment, padding, merged cells, repeating headers, and a one-click table style).

Prerequisite: before using any of these instructions, the workflow must already have a PDF created (with Create PDF).

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used. If the document doesn’t exist (or is not a PDF), the instruction simply does nothing.
  • The “last table”: every instruction except Insert Table works on the most recently inserted table in the document. So the usual order is: Insert Table first, then add rows and fill or style its cells. If no table has been inserted yet, these instructions do nothing.
  • Rows and columns are counted from 1: row 1, column 1 is the top-left cell. If you give a row or column number that is outside the table, it is adjusted to the nearest valid cell (it never fails).
  • Dynamic values (@name): in a text field (cell text, alignment, image path, widths, color hex) you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value.
  • “From variable” fields: numeric fields (row, column, sizes) can’t use @name. Instead they have a companion “from variable” field: leave it empty to use the normal field, or fill it with the name of a saved value to read the number from there. For example, Add Row can save the new row count under a name, and Set Cell Text can then read that name in its Row (from variable) field to write into the row just added.
  • Saving a result: Add Row can save the table’s resulting row count into a named value (its Save row count field). If you leave that field empty, nothing is saved.
  • Colors: every color is a hex code — 6 characters like 2E74B5, with or without a leading #. An invalid hex code becomes black. Leaving a color field empty means don’t change the color (see each instruction for what that implies).

Add Row .pdf

Adds a new empty row at the bottom of the last table.

When to use it: to grow a table one row at a time before filling its cells — for example inside a loop, one row per record.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Save row count Name under which the table’s resulting row count is saved. Empty = don’t save (empty) No

Important behavior: works on the last table; if there is no table, nothing happens. When Save row count is set, it stores the total number of rows after adding.

Apply Table Style .pdf

Applies a ready-made look to the last table: highlighted header row, alternating row shading, and a uniform border width.

When to use it: to make a plain table look finished in one step, without styling each cell by hand.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Header color hex Background color of the first (header) row, as a hex code. Supports @name 2E74B5 No
Alt row color hex Shading color of the alternating rows, as a hex code. Supports @name D6E4F0 No
Border width pt Width of the table borders, in points 0.5 No
Border width pt (from variable) Reads the border width from a saved value (empty) No

Important behavior: works on the last table; if there is no table, nothing happens. The first row is shaded with the header color and its text is set to bold white; every second data row is shaded with the alternate color.

Format Cell Text .pdf

Formats the text of one cell of the last table: bold, italic, underline, color, typeface, and size.

When to use it: to highlight the header row or a total after filling the table with Set Cell Text. Set Cell Text can already write bold and italic, but only while writing the text; this one formats what is already there, and adds color, typeface, and size.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row number Row of the cell (starts at 1) 1 No
Column number Column of the cell (starts at 1) 1 No
Bold true turns it on, false turns it off, empty leaves it as it is (empty) No
Italic true turns it on, false turns it off, empty leaves it as it is (empty) No
Underline true turns it on, false turns it off, empty leaves it as it is (empty) No
Color hex Text color, 6 hex digits without #. Empty = no change. Supports @name (empty) No
Font name Typeface of the text. Empty = no change. Supports @name (empty) No
Font size pt Size in points. 0 = no change 0 No
Row number (from variable) Reads the row position from a saved value (empty) No
Column number (from variable) Reads the column position from a saved value (empty) No
Font size pt (from variable) Reads the size from a saved value (empty) No

Important behavior: it acts on the last table in the document, like the rest of the PDF table instructions. Unlike the other formats, here the format is also given to the cell itself, so text written into it afterwards inherits it — formatting before or after Set Cell Text both work. Every attribute left empty (or 0) is left as it is. If there is no table, or the row or column does not exist, the instruction does nothing.

Insert Table .pdf

Inserts a new empty table with the chosen number of columns and one starting row.

When to use it: as the first step of any table — it creates the table that all the other instructions in this group then act on.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Columns Number of columns 3 No
Show borders Whether the table draws its cell borders true (yes) No
Columns (from variable) Reads the number of columns from a saved value (empty) No
Show borders (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: the column count is at least 1. The columns share the width evenly (about 16 cm total), and the table starts with one empty row — add more with Add Row.

Merge Cells .pdf

Merges a cell with its neighbors to the right (colspan) and/or below (rowspan) into a single bigger cell.

When to use it: to create a title cell that spans several columns, or to join cells vertically.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row of the top-left cell of the merge (from 1) 1 No
Column Column of the top-left cell of the merge (from 1) 1 No
Colspan How many columns the cell should span (1 = no horizontal merge) 1 No
Rowspan How many rows the cell should span (1 = no vertical merge) 1 No
Row (from variable) Reads the row from a saved value (empty) No
Column (from variable) Reads the column from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. A merge only occurs when Colspan or Rowspan is greater than 1, and it never extends past the table’s edges.

Prevent Row Page Break .pdf

Keeps a row from being split across two pages.

When to use it: for a row whose contents must stay together on one page.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row to keep together (from 1) 1 No
Row (from variable) Reads the row from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. The row is held together with the one below it, so marking the last row does nothing: there is no row underneath for it to be separated from.

Set Cell Alignment .pdf

Sets the horizontal and vertical alignment of the contents of a single cell.

When to use it: to center a heading cell, right-align numbers, or vertically center content in a tall cell.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row of the cell (from 1) 1 No
Column Column of the cell (from 1) 1 No
Horizontal alignment left, right, center, or justify. Supports @name left No
Vertical alignment top, center, or bottom. Supports @name top No
Row (from variable) Reads the row from a saved value (empty) No
Column (from variable) Reads the column from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. Unrecognized alignment values fall back to left / top.

Set Cell Background .pdf

Fills a cell — or an entire row — with a background color given as a hex code.

When to use it: to shade a header row, highlight a total row, or color a single cell.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row to shade (from 1) 1 No
Column Column to shade (from 1). -1 = shade the whole row -1 (whole row) No
Color (hex) Background color, 6 hex characters. Empty = don’t change anything. Accepts @name DCDCDC No
Row (from variable) Reads the row from a saved value (empty) No
Column (from variable) Reads the column from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. With Column left at its default -1 the whole row is shaded; give a column of 1 or more to shade just that one cell. A column outside the table (including 0) is brought back to the nearest real cell, like in the other cell instructions. If Color (hex) is left empty the instruction does nothing; an invalid hex code becomes black.

Set Cell Borders .pdf

Draws borders on the individual sides of a single cell, with a chosen width and color.

When to use it: to underline a cell, box a specific cell, or add a heavier line on one side.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row of the cell (from 1) 1 No
Column Column of the cell (from 1) 1 No
Top pt Width of the top border, in points. 0 = no top border 0 No
Bottom pt Width of the bottom border, in points. 0 = no bottom border 0 No
Left pt Width of the left border, in points. 0 = no left border 0 No
Right pt Width of the right border, in points. 0 = no right border 0 No
Color (hex) Border color, 6 hex characters. Empty = keep the color the border already had. Accepts @name 000000 No
Row (from variable) Reads the row from a saved value (empty) No
Column (from variable) Reads the column from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. A side gets a border only when its width is greater than 0; the chosen color applies to every side that is drawn. If Color (hex) is left empty the widths are still applied and the border color is left untouched; an invalid hex code becomes black.

Set Cell Image .pdf

Places an image inside a single cell, replacing whatever the cell contained.

When to use it: to put a logo, photo, or icon into a table cell.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row of the cell (from 1) 1 No
Column Column of the cell (from 1) 1 No
Image path File path of the image to insert. Supports @name image.png No
Width cm Width of the image, in centimeters. 0 or less = keep the image’s own size 3 No
Row (from variable) Reads the row from a saved value (empty) No
Column (from variable) Reads the column from a saved value (empty) No
Width cm (from variable) Reads the width from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. If Image path is empty, nothing is inserted. The cell’s previous contents are cleared first. The width is only forced when it is greater than 0.

Set Cell Text .pdf

Writes text into a single cell, replacing whatever the cell contained, with optional bold, italic, and alignment.

When to use it: to fill a table cell with a value — a header label, a data value, etc.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row of the cell (from 1) 1 No
Column Column of the cell (from 1) 1 No
Text Text to write into the cell. Supports @name (empty) No
Bold Make the text bold false (no) No
Italic Make the text italic false (no) No
Alignment left, right, center, or justify left No
Row (from variable) Reads the row from a saved value (empty) No
Column (from variable) Reads the column from a saved value (empty) No
Bold (from variable) Reads the yes/no value from a saved value (empty) No
Italic (from variable) Reads the yes/no value from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. The cell’s previous contents are cleared first. Unrecognized alignment values fall back to left.

Set Column Widths .pdf

Sets the widths of the last table’s columns from a list of centimeter values.

When to use it: to make some columns wider than others — for example a wide label column and narrow number columns.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Widths cm Column widths in centimeters, separated by | (for example 5|5|6). Supports @name 5|5|6 No

Important behavior: works on the last table; if there is no table, nothing happens. The values are applied to the columns in order, up to the number of columns the table actually has; extra values are ignored, and any value that isn’t a number is skipped.

Set Repeating Header Row .pdf

Marks a row as a header that repeats at the top of every page the table spans.

When to use it: for long tables that flow onto several pages, so the column headings reappear on each page.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row to mark as the repeating header (from 1) 1 No
Row (from variable) Reads the row from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens.

Set Row Column Padding .pdf

Sets the inner spacing (padding) between a cell’s border and its contents.

When to use it: to give a table more breathing room, or tighten it up.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Row Row whose top/bottom padding is set (from 1) 1 No
Column Column whose left/right padding is set (from 1) 1 No
Top pt Space above the contents, in points 2 No
Bottom pt Space below the contents, in points 2 No
Left pt Space to the left of the contents, in points 4 No
Right pt Space to the right of the contents, in points 4 No
Row (from variable) Reads the row from a saved value (empty) No
Column (from variable) Reads the column from a saved value (empty) No

Important behavior: works on the last table; if there is no table or it is empty, nothing happens. Because of how PDF tables work, top and bottom padding apply to the whole row you name, and left and right padding apply to the whole column you name — not just to the single cell where they cross.
