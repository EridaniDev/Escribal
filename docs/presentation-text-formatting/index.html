Presentation

Text & formatting

This group of instructions writes and formats text on slides. It inserts a new text box and replaces the text of a shape, and it applies character formatting (font family, size, color, bold, italic, underline, strikethrough, highlight, superscript/subscript, and letter case) and paragraph formatting (alignment, line and paragraph spacing, indentation, and bullet or numbered lists) to text that is already inside a shape. It can also insert a clickable hyperlink and set how text sits vertically inside its box.

Prerequisite: before using any of these instructions, the workflow must already have a PPTX presentation created or opened (with Create presentation). Except for Insert Text Box (which creates its own box), these instructions format text that is already inside a shape — for example a box made with Insert Text Box or a shape filled with Add Text To Shape.

These concepts recur across several instructions in this group; they are explained here once.

  • Document: indicates which document in the workflow the instruction applies to. If left empty, the current document is used.

  • The shape is chosen by name; slides and paragraphs by number:

    • Shape name — the name of the shape whose text you want to touch, as the rest of the presentation instructions do it. Leave it empty to affect every shape on the slide; if several shapes share the name, all of them are affected. Insert Text Box has a Shape name field so you can name the box you create and target it later.
    • Slide number — the position of the slide; the first slide is 1, the second is 2, and so on.
    • Paragraph number — the position of the paragraph (line) inside the shape’s text, starting at 1. In most instructions, -1 means “all paragraphs” (format the whole shape). Insert Hyperlink is the exception: it needs one specific paragraph.

  • Only shapes that contain text are affected: shapes without text are skipped.

  • Names or numbers that do not exist do nothing: if no shape matches the name, or the slide or paragraph number does not exist, the instruction does nothing and the workflow continues with the next instruction.

  • Measurements, colors, and percentages: positions, sizes, and indentation are given in centimeters (cm); font and spacing sizes in points (pt); colors as hex codes (for example FF0000), with or without a leading #; line spacing and bullet size as a percentage (100 = normal).

  • Dynamic values (@name): in any text field you can type @ followed by the name of a value saved earlier in the workflow, and it will be replaced by that value. For example, if you saved a color in brandColor, you can type @brandColor in a Color field.

  • Saving a result: Insert Text Box offers a Save shape name in field that stores the new box’s name under a name you choose. If left empty, nothing is saved. Leaving Shape name empty gives the box an automatic name (TextBox 3, for example) — save it here and the other text instructions can find the box by that name.

  • “From variable” fields: the @name trick only works in text fields. So that a numeric field (like Slide number or Font size (pt)) or a yes/no field (like Bold) can also take its value from a saved value, each one has a companion “from variable” field:

    • If you leave it empty, the value typed in the normal field is used.
    • If you fill it in with the name of a saved value, the engine ignores the normal field and uses that variable’s value.

    This is mainly for chaining instructions (one instruction saves a value, the next one reads it). If you only work with fixed values, you can ignore these fields.

Find Text In Presentation .pptx

Looks for a text across every slide and saves what it finds.

When to use it: to decide what the workflow does next — for example, only replace a marker if the presentation still has it.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Search text Text to look for. Supports @name (empty) Yes
Case sensitive Yes = Cat and cat are different No No
Case sensitive (from variable) Reads yes/no from a saved value (empty) No
Save found key Name to save yes/no under (empty) No
Save count key Name to save how many occurrences under (empty) No
Save slide key Name to save the first slide that has it under (empty) No

Important behavior: this instruction reads only — it changes nothing. If Search text is empty, nothing happens and nothing is saved. When there is no match the count is 0 and the slide is -1. A text split by formatting inside the same line is not found.

Insert Hyperlink .pptx

Adds a clickable link at the end of a paragraph — either to a web/email address or to another slide in the same presentation.

When to use it: to link a word to a website, or to make text that jumps to another slide when clicked during the show.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the shape is on (starts at 1) 1 No
Shape name Shape on the slide that holds the text; empty = every shape on the slide. Supports @name (empty) No
Paragraph number Paragraph (line) to add the link to (starts at 1) 1 No
Link text The visible text of the link. Supports @name Click here No
Link URL Web or email address to link to. Supports @name (empty) No
Target slide number Slide to jump to (0 or more); -1 = none -1 No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Paragraph number (from variable) Reads the paragraph number from a saved value (empty) No
Target slide number (from variable) Reads the target slide number from a saved value (empty) No

Important behavior: provide either a Link URL (external link) or a Target slide number of 0 or more (internal jump to that slide). If you give a URL and leave Target slide number at -1, an external link is made; a target slide of 0 or more makes an internal jump instead. The URL must be a full web/email address (for example https://… or mailto:…); if it is not a full address, nothing happens. If you provide neither a URL nor a valid target slide, the instruction does nothing. The link text is added as a new underlined blue run at the end of the chosen paragraph of every shape matching Shape name; if no shape matches, or the slide or paragraph number does not exist, the instruction does nothing. Paragraph number must be 1 or more here — -1 does nothing.

Important behavior: the box is added as a new shape at the end of the slide’s shapes. If you leave Shape name empty it gets an automatic name (TextBox 3, for example); giving it a name — or saving the automatic one with Save shape name in — is what lets the other text instructions find it later.

Replace Text In Presentation .pptx

Replaces a text on every slide, or on one slide only.

When to use it: the usual way to fill a template — build the deck with markers and replace them with values gathered by the workflow.

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Search text Text to look for. Supports @name (empty) Yes
Replace with Text to put in its place. Supports @name (empty) No
Slide number Slide to work on, counting from 1. -1 = every slide -1 No
Case sensitive Yes = Cat and cat are different No No
Slide number (from variable) Reads the slide from a saved value (empty) No
Case sensitive (from variable) Reads yes/no from a saved value (empty) No
Save count key Name to save how many were replaced under (empty) No

Important behavior: if Search text is empty, nothing happens. Replace with can be empty: that erases the found text. A slide that doesn’t exist does nothing. The replacement happens within each piece of text as it is stored, so a marker split by formatting (half of it in bold) is not matched — write markers in one style.

Set Baseline Shift .pptx

Raises or lowers text relative to the normal line (superscript or subscript).

When to use it: for exponents (like m²), footnote marks, or chemical formulas (like H₂O).

Parameter Meaning Default Required
Document Document the instruction applies to (current document) No
Slide number Slide the shape is on (starts at 1) 1 No
Shape name Shape on the slide that holds the text; empty = every shape on the slide. Supports @name (empty) No
Paragraph number Paragraph to change; -1 = all paragraphs -1 No
Mode superscript, subscript, or none. Supports @name superscript No
Slide number (from variable) Reads the slide number from a saved value (empty) No
Paragraph number (from variable) Reads the paragraph number from a saved value (empty) No

Important behavior: superscript raises the text, subscript lowers it, and none returns it to the normal baseline. Any other value is treated as superscript.
