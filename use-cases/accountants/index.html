Use case

Escribal for accountants

Every close repeats the same work. Set it up once and run it each month with the new export.

Every close repeats the same work: export from the accounting system, sort the data, total it by customer or by account, move the figures into a formatted document and produce one per customer. The work is identical every month and, even so, it is done by hand every month, with the risk that a figure gets copied wrong.

With Escribal you put that work together once, as a list of instructions, and run it again each month with the new data.

What you gain

  • Documents in batch. Account statements, letters, summaries or certificates, one per customer, from the same list of data.
  • Exact arithmetic. Calculations are done in base ten, so 0.1 + 0.2 gives 0.3, with no rounding differences.
  • Numbers in the format you need. $1,234.56, 1.234,56 €, zero-padded or aligned in a column.
  • Nothing half done. If an instruction fails, no file is written, and the program says which one failed and why.

Your clients’ data stays where it is

Escribal runs on your computer. There is no cloud account and no uploading of files, and the program carries no telemetry. The detail is in the privacy policy.

See it with real data

The monthly account statement example goes from a CSV of invoices to a Word document with one line per customer and an Excel sheet with a chart. Download it, run it, then replace the CSV with next month’s and run it again.
