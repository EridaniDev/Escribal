Use case

Escribal for analysts

The same sheet of totals, the same deck of charts, the same clean export, built from new data without rebuilding anything.

The same documents get put together over and over with new data: the sheet with the totals, the presentation with the charts, the document for management, the clean export for another system. The macros that automate it tend to be fragile, and only the person who wrote them understands them.

With Escribal the process is a list of instructions on a canvas. You build it once, and the next time you change the data and press Run.

What you gain

  • Read and produce in the same workflow. Take data from your own files or from PostgreSQL and deliver documents, spreadsheets, presentations or PDFs.
  • Group and aggregate (sum, average, minimum, maximum, count) without writing formulas.
  • A process you can see. The instructions are laid out in order on a canvas, so anyone on the team can read it and maintain it.
  • An AI agent that builds or changes the instructions for you. See how to connect it.

Databases, read-only

A workflow can query a PostgreSQL database and use the result like any other list of data. The query is read-only (the server itself enforces that) and the password is not saved in the workflow: it is asked for when you run it and never reaches any document.

One workflow, several documents

One workflow can read a CSV, calculate, and produce a spreadsheet and a PDF at the same time. The monthly close example does exactly that: from three CSV files it writes a workbook, a board deck, a one-page PDF and a report.
