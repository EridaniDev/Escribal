Use cases

Escribal is for the document you are going to make again next month with different data.

Examples

What comes out of a workflow

  • Monthly account statement

    Excel file of transactions

    → A PDF per customer

  • Balance letters

    List of customers

    → A Word letter per customer, with their balance and their date

  • Sales summary by region

    CSV exported from the system

    → A presentation with one slide and one chart per region

  • Branch consolidation

    Several CSV files

    → An Excel file with one sheet per branch and one of totals

  • Document for management

    PostgreSQL query

    → A Word document with tables and formatted figures

  • Certificates in batch

    List of participants

    → A PDF per person

  • Cleaning up exports

    Untidy JSON or CSV

    → A CSV filtered, sorted and with the columns renamed

To see one built end to end, the monthly account statement example can be downloaded and run.

By trade: accountants and analysts.
