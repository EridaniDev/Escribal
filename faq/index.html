FAQ

Frequently asked questions

Whether you need to program, where your data goes, and what it costs.

Do I need to know how to program?

No. Instructions are picked from a menu and configured in a panel. And if you would rather not build them yourself, your AI agent can.

What kind of documents can I generate?

Any document that repeats with different data: account statements, letters, reports, presentations, spreadsheets, certificates or data exports. The use cases list some.

Is my data uploaded anywhere?

No. Escribal works on your computer. If you use an AI agent, it sees the instructions it builds, but not your database passwords. The detail, with the only three moments when the program uses the network, is in the privacy policy.

Can I use my own document, spreadsheet or presentation templates?

Yes. Escribal opens existing documents and works on a copy, so the original is left untouched.

Where can it read data from?

From its own formats (spreadsheets, documents, presentations, CSV, JSON, Markdown and text) and from PostgreSQL databases. PDF can be written, but not read.

What happens if an instruction fails?

Nothing is saved. The program marks the instruction that failed in red and explains why. See reading what a run tells you.

Which AI agents work with it?

Any AI agent that supports MCP servers. Connecting it takes a minute: the program gives you the configuration already filled in. See connecting your AI agent.

Why not just ask an AI for the document?

Because a workflow is built once and runs forever: after that it runs without AI, with the same figures every time and no cost per run. You can review it instruction by instruction, it runs on your computer, and one single workflow writes several documents with the same figures. Your AI agent can build it for you.

Which systems does it run on?

Windows, and it is downloaded from the Microsoft Store.

How much does it cost?

USD 7.99 per month or USD 63.99 per year, and the first week is free. See pricing.

What is Escribal not?

It is not a word processor: a letter you write only once is faster to type yourself. It is not a design tool: its strength is data and repetition, not free-form layout. And it is not a cloud service or an electronic signature platform.

How do I report a problem or suggest something?

Write to support@escribal.com.
