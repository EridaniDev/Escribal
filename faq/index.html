FAQ

Frequently asked questions

Whether you need to program, where your data goes, and what it costs.

Do I need to know how to program?

No. Instructions are picked from a menu and configured in a panel. And if you would rather not build them yourself, your AI assistant can.

What kind of documents can I generate?

Any document that repeats with different data: account statements, letters, reports, presentations, spreadsheets, certificates or data exports. The use cases list some.

Is my data uploaded anywhere?

No. Escribal works on your computer. If you use an AI assistant, it sees the instructions it builds, but not your database passwords. The detail, with the only three moments when the program uses the network, is in the privacy policy.

Can I use my Word, Excel or PowerPoint templates?

Yes. Escribal opens existing documents and works on a copy, so the original is left untouched.

Where can it read data from?

From its own formats (Excel, Word, PowerPoint, CSV, JSON, Markdown and text) and from PostgreSQL databases. PDF can be written, but not read.

What happens if an instruction fails?

Nothing is saved. The program marks the instruction that failed in red and explains why. See reading what a run tells you.

Which AI assistants work with it?

Claude and any assistant that supports MCP servers.

Which systems does it run on?

Windows, and it is downloaded from the Microsoft Store.

How much does it cost?

USD 19.99 per year. See pricing.

What is Escribal not?

It is not a word processor: for a letter you write once, Word is faster. It is not a design tool: its strength is data and repetition, not free-form layout. And it is not a cloud service or an electronic signature platform.

How do I report a problem or suggest something?

Write to support@escribal.com.
