What it is

Do it once. Escribal does it every time.

A workflow is an ordered list of instructions you put together on a canvas. The instructions are saved, so next time you build nothing again: you change the data, press Run, and the document comes out the same, with the new information.

  1. 1

    Read the data

    Open the source files or query the database.

  2. 2

    Transform it

    Repeat for each row or customer, decide based on a value, calculate.

  3. 3

    Generate the documents

    Write them, one or many, at the end.

What it includes

More than 700 instructions, in more than 90 groups

Write cells and formulas, build tables and charts, add slides, set styles, filter and join data. Every instruction is picked from a menu, organized by format and by task, and configured in a panel.

  • Excel: cells, formulas, formatting, sheets, tables, charts, named ranges, protection.
  • Word: paragraphs, styles, tables, images, headers and footers, comments and tracked changes.
  • PowerPoint: slides, text boxes, shapes, tables, charts, notes and animations.
  • CSV, JSON, Markdown and TXT: read, filter, sort, join, group and export.

How it helps you

Your AI assistant does the work for you

Describe what you need in your own words (“a document for each customer with their figures”) and the assistant looks up the instructions, builds the workflow, checks it, runs it and fixes it until it comes out right.

  • Not a black box: a workflow you open, read instruction by instruction, and run again without the AI.
  • Reproducible: the same instructions produce the same document every time.
  • Your database passwords never pass through the AI.

What it guarantees

All or nothing, and the failure has a name

If an instruction fails halfway through, no file is saved: there are no half-written documents to go through. The instruction that warned is left in amber and the one that stopped the run in red, each with its explanation beside it.

  • The original file is not touched when you open it, unless you choose to save over it.
  • Escribal opens your Word, Excel or PowerPoint templates and works on a copy.

And also

Everything a document that repeats needs

  • Loops and conditions

    Repeat for each row, customer or region with For Each, and decide based on a value with If.

  • Exact arithmetic

    Calculations in base ten: 0.1 + 0.2 gives 0.3. Round, aggregate, group and format numbers.

  • PostgreSQL, read-only

    Query a database and use the result like any other list. The password is never saved in the workflow.

  • Variables

    What one instruction reads, the next one uses, by writing @name.

  • Several documents at once

    One workflow can read a CSV, calculate, and produce an Excel file and a PDF at the same time.

  • On your computer

    No cloud account, no uploading of files and no telemetry. Your clients’ data stays where it is.

Who it is for

For anyone who makes the same document again and again

You do not need to program, or to work in any particular field. What matters is that the document repeats, with different data each time.

  • One for each

    The same document for every customer, student or participant (letters, statements, certificates) from a single list.

  • The same every time

    The report of every week or every month, where the figures change and the shape does not.

  • From one format to another

    Data that arrives untidy and has to come out clean, in another file or for another system.

Two examples by trade: accountants and analysts. Or see what comes out of a workflow.

What it is not

Escribal is for the document you are going to make again next month

  • Not a word processor

    For a letter you write once, Word is faster.

  • Not a design tool

    Its strength is data and repetition, not free-form layout.

  • Not a cloud service

    Nor an electronic signature platform. It runs on your computer.
